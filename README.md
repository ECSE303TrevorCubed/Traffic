## Compiling and Running the Code
1. Connect your Arduino Uno to your machine
2. Open Arduino IDE and configure the port your board is connected on
3. Open the `Traffic.ino` file (note that the file must be in a subdirectory of the same name to be compatible with the IDE)
4. Compile the code by pressing the blue check in the top left of your IDE
5. Upload the code to the board by pressing the arrow button in the top left of the IDE (directly to the right of the compilation button)
6. The code will immediately start running on the board, though you can reload the compiled sketch by pressing the reset button on the board
